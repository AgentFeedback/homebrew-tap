# AgentFeedback Homebrew tap

This repository is a generated distribution mirror. The source of truth is
[AgentFeedback/agentfeedback `.goreleaser.yaml`](https://github.com/AgentFeedback/agentfeedback/blob/main/.goreleaser.yaml).
Stable releases update `Casks/agentfeedback.rb` through the local release step;
prereleases do not replace the stable cask. Do not maintain the cask independently.

With current Homebrew (7.0.1 or later), on macOS or Linux, x86-64 or ARM64:

```sh
brew install --cask agentfeedback/tap/agentfeedback
agentfeedback version
agentfeedback init
```

For upgrade, reinstall, uninstall, macOS security limitations and maintainer
publication/recovery procedures, see the canonical
[Homebrew documentation](https://github.com/AgentFeedback/agentfeedback/blob/main/docs/releases.md#homebrew-publishing).
Uninstalling preserves configuration and feedback data. The binary is not
Apple-signed or notarized; this cask does not disable macOS security checks.

Report issues in the [source repository](https://github.com/AgentFeedback/agentfeedback/issues).
